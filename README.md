# InvoX AI

**InvoX AI** is an AI-powered invoice processing assistant that extracts useful information from invoices, stores it in MongoDB, and allows users to interact with their invoice data using natural-language queries.

## 🚀 Features

* User Signup & Login
* Invoice Upload
* Invoice Data Extraction
* MongoDB Storage
* Invoice Search & Filtering
* Natural-Language Queries
* AI-powered Invoice Assistant

## ☁️ Azure AI

**Azure AI Foundry** is used to build and manage the AI agent.

The AI agent understands user queries and retrieves relevant invoice information.

## 🔄 Workflow

```text
Invoice Upload
      ↓
Data Extraction
      ↓
MongoDB
      ↓
Azure AI Agent
      ↓
User Query & Response
```

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **AI:** Azure AI Foundry & AI Agent
* **Authentication:** JWT
* **Version Control:** Git & GitHub

## 🎯 Objective

To simplify invoice management by combining **invoice processing, database storage, and AI-powered natural-language interaction**.
